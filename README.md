# 价格行为交易复盘 APP

版本：1.0.0

这是一个本地优先、离线可用的静态网页 APP。第一版围绕低负担交易记录、三阶段复盘、图片证据、策略标签、错误成本和核心统计实现，不包含行情、下单、账户连接、云同步或社区功能。

## 数据模型

- `trades`：交易主记录，包含市场、品种、方向、状态、入场计划、平仓结果、复盘结论和历史策略版本。
- `images`：保存在 IndexedDB 中，结构化交易数据只保存图片 ID、分类、封面关系和文件路径。
- `strategies`：价格行为策略库，策略带版本、适用环境、禁止条件和检查项。
- `settings`：账户、常用品种、期货品种预设、最近使用值、筛选方案、模板、费用模式和备份时间。
- `drafts`：每个市场一份自动保存草稿，刷新或关闭页面后可继续。
- `trash`：删除交易先进入回收站，可恢复。

## 信息架构

- 底部四栏：期货、黄金外汇、BTC、汇总数据。
- 前三栏：本月统计、待复盘数量、常用品种、最近交易、筛选入口、快速新建。
- 交易录入：入场计划、平仓结果、交易复盘三阶段，任一阶段可保存退出。
- 详情页：按真实时间线展示市场背景、计划、截图、成交、出场、执行质量、错误标签和复盘结论。
- 汇总页：市场范围与组合筛选、资金成绩单、执行质量成绩单、图表、错误成本和可追溯交易列表。
- 数据页：完整 ZIP 备份、合并导入、CSV 导出、策略库、回收站、预设与主题。
